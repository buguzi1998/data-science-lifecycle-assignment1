# Automobile Price Analysis

This project studies the automobile dataset to find out which features
affect car price the most. I cleaned the data, explored it with statistics
and graphs, compared prices across groups like body style and drive wheels,
and picked the most important features for predicting price.

Course: Data Science Lifecycle, Uganda Christian University (Advent 2026)

- Assignment1.ipynb (notebook with code, outputs and explanations)
